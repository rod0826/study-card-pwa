# 시험 전 최종 점검 50문항 선별

작성일: 2026-10-05. 대상: 중2 2학기 중간고사 국어·과학.

## 제외와 선별 기준

- 기존 핵심 70문항(커밋 `91d0169`, [선별 기록](CORE_70_REVIEW.md))을 과목별로 전부 제외했다. 앱에는 새로 선정한 50문항씩만 연결한다.
- 축소 전 원본 국어 194문항·과학 219문항에서 기존 70문항을 뺀 후보는 국어 124문항·과학 149문항이다. 원본은 커밋 `91d0169^`에서 확인했다.
- 문제를 새로 만들어 바꾸지 않고, 원본의 ID·질문·정답·허용 답안·힌트·출처를 그대로 유지했다.
- 국어는 작품의 소재와 인물 태도, 역사적 맥락, 읽기 단계, 갈등 표현의 구별을 우선했다. 월드컵은 글의 취지와 확대 의미를 확인하며 연도별 직책 암기는 최소화했다.
- 과학은 그래프의 증가·포화·감소 구간, 호흡과 광합성의 비교, 영양소 검출과 침 실험, 소화·흡수 구별, 혈관·혈액·순환 경로, 들숨·날숨과 배설 과정의 구별을 우선했다.
- 같은 답을 반복 확인하는 문항은 줄였다. 식물의 어두운 곳 기체 변화, 침 실험의 비교, 헤모글로빈의 결합·분리는 대조해서 확인할 가치가 있어 함께 남겼다.
- 기존 70문항과 카드 ID 및 질문의 중복은 각각 0개이며, 국어 12범주·과학 10단원을 모두 포함한다. 이미 학습한 개념을 다른 관점에서 확인하는 문항은 포함한다.
- 제공된 자료 범위에서 선정했다. 원본 검토 기록에서 제외한 불확실한 월드컵 국가 목록이나 잘못 일반화할 수 있는 과학 설명은 추가하지 않았다.

## 기록과 배포

- 기존 기기 학습 기록을 삭제하지 않는다. 이번에 복원한 원본 문항을 이전에 푼 적이 있다면 그 기록은 유지된다. 전체 50문항을 다시 점검하려면 학습 설정에서 `전체 카드`를 선택한다.
- 검증 통과: 각 50문항, 기존 70문항과 ID·질문 중복 0개, 전체 범주 포함, 원본 카드 전체 필드 일치, 데이터 458장, 이어풀기 회귀, 캐시 자산 27개, JavaScript 문법.
- 공개 배포 완료: 문항 교체 커밋 `1c53d47`, GitHub Pages 성공. 공개 두 과목 JSON과 로컬 최종본이 정확히 일치한다. Chrome에서 과목별 50장 표시와 콘솔 오류 없음을 확인했다.
- 배포는 기존 GitHub Pages `main` 브랜치를 이용한다. 문제 발생 시 이 변경 커밋을 되돌리고 다시 배포할 수 있다.
