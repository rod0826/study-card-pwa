# JianStudy

중학교 시험을 국어·영어·수학·과학 과목별 카드 퀘스트로 준비하는 정적 PWA입니다.

## 현재 상태

- 최근 문서 업데이트: 2026-10-05
- 기준 앱: 정적 HTML/CSS/JavaScript PWA
- 로컬 실행: `http://localhost:5173`
- 공개 사이트: `https://rod0826.github.io/study-card-pwa/`
- 공개 사이트는 GitHub Pages의 `main` 브랜치에서 배포합니다.

현재 중학교 2학년 2학기 중간고사는 **국어·과학 각 최종 점검 50문항**입니다. 직전 핵심 70문항을 모두 제외하고, 축소 전 원본에서 국어 12개 범주와 과학 10개 단원을 포함하도록 새로 선정했습니다. 이전 시험 358장을 포함한 전체 카드 수는 458장입니다. [최종 선별 기록](docs/FINAL_50_REVIEW.md)에서 기준과 전체 문항을 확인할 수 있습니다.

## 2026-10-05 시험 전 최종 점검 50문항

- 기존 70문항은 과목별로 모두 제외했습니다. 남은 원본 후보 국어 124문항·과학 149문항에서 각각 50문항을 선정했습니다. 직전 70문항과 ID·질문 중복은 0개입니다.
- 국어는 작품 해석·역사적 맥락·읽기 단계·갈등 표현 구별, 과학은 실험·그래프·소화와 흡수·순환·호흡·배설의 비교를 우선했습니다. 모든 범주를 유지하며 원본 카드의 ID·정답·힌트·허용 답안·출처를 그대로 사용합니다.
- 기존 학습 기록은 유지합니다. 이번 50문항을 예전에 풀었다면 기록이 남아 있을 수 있으므로, 마지막 점검은 `복습 범위 → 전체 카드`에서 `퀘스트 시작`으로 시작합니다.
- 검증: 카드 데이터 458장, 캐시 자산 27개, JavaScript 문법 및 이어풀기 회귀 검사 통과. 회귀 검사에 각 50문항·기존 70문항 제외·전체 범주 포함을 반영했습니다. Chrome에서 과목별 50장 표시와 국어·과학 첫 문항 진입을 확인했습니다.
- 공개 배포 완료: 문항 교체 커밋 `1c53d47`, GitHub Pages 배포 성공. 공개 국어·과학 JSON이 로컬 검증본과 정확히 일치하며, Chrome 공개 화면에서 각 50장 표시와 콘솔 오류 없음을 확인했습니다.

## 2026-10-05 핵심 70문항·이어풀기 수정 및 공개 배포

- 국어 194장 → 70장, 과학 219장 → 70장. 선별 기준·범주별 개수·전체 선택 문항은 [선별 기록](docs/CORE_70_REVIEW.md)에 있습니다. 제공 자료를 기준으로 하며 별도의 학교 최종 시험 범위표는 확인하지 않았습니다.
- 남긴 문항의 기존 ID를 유지하고 기존 학습 기록을 삭제하지 않습니다. 제외 문항은 현재 진행률 계산에서 제외됩니다.
- 문항별 정답·오답 기록은 이미 `localStorage`에 저장되고 있었습니다. 종료 시 사라지던 것은 메모리에만 있던 퀘스트 순서·현재 위치·이번 통계였습니다.
- 퀘스트 시작과 매 채점 직후 시험별 큐·현재 위치·통계를 기기에 저장합니다. 재실행 시 마지막 시험의 미완료 퀘스트를 자동 복원하며, 학습 설정에서도 `이어서 풀기`를 선택할 수 있습니다. `퀘스트 시작`은 선택한 설정으로 새 퀘스트를 시작합니다. 채점 전 입력 중이던 답과 힌트 펼침 상태는 저장하지 않습니다.
- 오답·헷갈림 문항의 재출제 순서도 유지합니다. 원래 문항 수는 각 70장이며 재출제에 따라 풀이 횟수는 늘 수 있습니다.
- 기존 앱 버전에서 저장하지 않았던 퀘스트 위치는 소급 복원할 수 없습니다. 남아 있는 문항별 기록을 이용해 `새 카드`·`오답 카드`를 선택할 수 있습니다.
- 로그인·서버 DB는 필요하지 않습니다. 기기·브라우저 간 동기화는 제공하지 않으며 시크릿 모드, 사이트 데이터 삭제, 저장 차단 환경에서는 기록이 유지되지 않을 수 있습니다. 저장 실패 시 안내가 표시되지만 학습은 계속할 수 있습니다.
- 검증: 카드 데이터 498장, 캐시 자산 27개, JavaScript 문법 검사 통과. `node scripts/test-session.mjs`로 종료·복원, 재출제 큐, 삭제된 카드 정리, 완료 후 종료, 화면 이탈 후 채점 방지, 저장 실패를 검사했습니다. 로컬 Chrome에서 70장씩 표시, 오답 기록, 탭 종료 후 같은 문항·위치·통계 복원, 이어풀기 버튼을 확인했습니다. 휴대폰 PWA 강제 종료·재실행은 실기기에서 확인하지 못했습니다.
- 공개 배포 완료: 이어풀기 수정 커밋 `3090a95`, 핵심 문항 선별 커밋 `91d0169`. GitHub Pages 배포 성공을 확인했고, 공개 사이트에서 국어·과학 각 70장 표시와 브라우저 오류가 없음을 확인했습니다.
- 사용자 확인: 배포된 버전으로 확인한 뒤 **“제대로 동작되네요”**라고 정상 동작을 확인했습니다. 사용 기기·브라우저·실행 방식은 별도로 전달받지 않았습니다. 위 실기기 미검증 내용은 개발 과정에서 직접 확인한 범위를 뜻하며, 사용자 확인 결과와 구분합니다.

### 검사 결과

### 개선 필요 항목 — 미수정

1. **서비스 워커 등록 시점:** 비동기 데이터 초기화가 끝난 뒤 `load` 이벤트를 구독하므로, 이벤트가 먼저 발생하면 등록이 누락될 수 있습니다. 데이터 초기화와 별개로 등록하도록 개선해야 합니다.
2. **중복 학습 시작:** 동시에 두 번 시작하면 역사 카드 122장이 244장으로 중복되는 현상을 재현했습니다. 로딩 중 버튼 잠금과 중복 실행 방지가 필요합니다.
3. **화면 전환 타이머:** 정답 처리 후 0.65초 안에 학습 설정으로 나가도 예약된 타이머가 결과 화면으로 덮어쓰는 현상을 재현했습니다. 화면 이탈 시 예약된 전환을 취소해야 합니다.
4. **숫자 자동 채점:** 현재 정규화는 `-3`과 `3`, `1.5`와 `15`를 동일하게 처리합니다. 수학·과학 카드 투입 전 부호와 소수점을 보존하는 채점 규칙이 필요합니다.
5. **학습 기록 보호:** 브라우저 저장소 쓰기 실패 처리와 기록 백업·복원 기능이 없습니다. 저장 실패 안내와 JSON 내보내기·가져오기를 개선 항목으로 남깁니다.

### 학습 기능

- 전체 카드 학습과 과목별 학습을 지원합니다.
- 전체·새 카드·취약 카드·오답 카드 복습 범위를 지원합니다.
- 무작위 순서와 교과서 순서를 선택할 수 있습니다.
- 힌트, 정답 확인, 맞음·헷갈림·틀림 기록을 제공합니다.
- 헷갈린 카드와 틀린 카드는 학습 큐 뒤에 다시 배치됩니다.
- 입력한 답이 정답과 일치하면 즉시 맞음으로 기록합니다.
- 자동 채점 시 공백과 일반적인 문장부호 차이를 무시합니다.
- 카드의 `acceptedAnswers` 배열로 복수 정답을 등록할 수 있습니다.
- 정답을 맞히면 짧은 색종이 효과와 응원 문구가 표시됩니다.
- 이전 버전의 브라우저 학습 기록을 새 저장 구조로 자동 이전합니다.

### 작업 공간 정리

- 구형 인수인계 문서와 세트 목록은 `docs/archive/`, `data/legacy/`에 보존했습니다.

- 카드 파일에서 오프라인 자산 목록과 캐시 버전을 자동 생성합니다.

## 원본 자료에서 카드 만들기

앱 자체에 파일을 업로드하는 방식은 사용하지 않습니다. 프로젝트의 비공개 원본 자료 폴더에 파일을 넣은 뒤 카드 생성을 요청합니다.

```text
../source-materials/<시험 ID>/<과목 ID>/
├── textbook.pdf
├── class-note.jpg
└── worksheet.png
```

카드 생성 흐름:

1. PDF 텍스트 추출 또는 이미지 OCR
2. 단원과 핵심 내용 구분
3. 빈칸·정답·힌트 후보 생성
4. 원본과 대조하고 불확실한 내용 제외
5. `data/exams/<시험 ID>/<과목 ID>/core.json` 저장
6. 시험 `index.json` 연결
7. 데이터 검사와 실제 학습 확인

원본에서 확인되지 않는 내용은 추가하지 않으며, 원본 사진과 PDF는 공개 저장소에 올리지 않습니다.
